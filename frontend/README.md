## How to run it? ⚙

1. Clone repository:

   ```bash
   git clone git@github.com:DevPacho/physiohelp.git
   ```

2. Change directory:

   ```bash
   cd physiohelp/frontend
   ```

3. Install dependencies:

   ```bash
   pnpm i
   ```

4. Run project:

   ```bash
   pnpm dev
   ```

5. Open http://localhost:5173 in your preferred browser.
